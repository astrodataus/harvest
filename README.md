# Harvest · Kristi Ridge

A harvest-week decision app for an invented Napa Valley estate, built by Astrodata as a demo of what a data product can be when the map, the model and the decision live on one screen.

Ten blocks are still on the vine and rain arrives Thursday afternoon. The app shows where every block's fruit stands this morning, what each picking day is worth, which blocks earn the dry days, and lets the user decide, prepare and send the week's plan to the crews.

Kristi Ridge does not exist. Every figure, forecast, price and name is synthetic, seeded once, so nothing here describes a real winery.

Open `index.html` in a browser, or visit the published page. The page is self-contained apart from the images and the intro film in `media/`, and two Google Fonts.

Design language: Taliesin, by Wagabaza.
